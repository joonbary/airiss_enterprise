# 🌐 AIRISS v4 도메인 설정 가이드

## 🎯 현재 상황: AWS Amplify 도메인 설정

### ✅ 즉시 사용 (추천)
**"도메인 추가" 건너뛰기를 클릭하세요!**

이유:
- 무료 AWS 도메인으로 즉시 사용 가능
- SSL 인증서 자동 적용
- 전 세계 CDN 포함
- 나중에 언제든 커스텀 도메인 추가 가능

### 📍 예상 결과
```
기본 URL: https://main.d[랜덤숫자].amplifyapp.com
또는: https://airiss-v4-production.amplifyapp.com
```

---

## 💡 나중에 도메인 추가하는 방법

### 1. AWS Amplify Console 접속
- console.aws.amazon.com/amplify/
- 앱 선택 → "Domain management" 탭

### 2. 도메인 옵션 선택

#### Option A: 새 도메인 구매 (Route 53)
```
추천 도메인:
- airiss.co.kr (연 $15)
- talent-ai.com (연 $12)  
- okfinance-ai.com (연 $12)
- airiss-enterprise.com (연 $12)
```

#### Option B: 기존 도메인 연결
```
설정 방법:
1. 도메인 DNS 관리 페이지 접속
2. CNAME 레코드 추가:
   - 이름: www (또는 @)
   - 값: AWS에서 제공하는 도메인
3. 전파 대기 (최대 48시간)
```

## 🎯 비즈니스 관점에서 도메인 전략

### 📊 단계별 도메인 전략

#### Phase 1: 개발/테스트 (현재)
```
도메인: 무료 AWS 도메인
용도: 내부 테스트, 데모, 초기 검증
비용: $0
```

#### Phase 2: 정식 서비스 (1-3개월)
```
도메인: airiss.co.kr
용도: OK금융그룹 내부 서비스
비용: 연 $15
```

#### Phase 3: B2B 확장 (6개월-1년)
```
도메인: airiss-enterprise.com
용도: 외부 기업 서비스 제공
비용: 연 $12 + 프리미엄 기능
```

#### Phase 4: 글로벌 진출 (1년+)
```
도메인: 
- airiss.com (메인)
- airiss.co.jp (일본)
- airiss.sg (싱가포르)
용도: 글로벌 시장 진출
비용: 연 $50-100
```
